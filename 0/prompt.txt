## Resumen ejecutivo

No es un i18n de Laravel "estándar de archivos". Es un **sistema híbrido JSON-en-disco + overrides en base de datos**, gestionado íntegramente desde el admin por el módulo `modules/AdminLanguages`, con **auto-traducción vía Google Translate** y un **scanner** que extrae las claves del código fuente. Las claves son **texto literal en inglés** (estilo JSON de Laravel), no `archivo.clave`.

## 4. Gestión de traducciones en el admin

Sí, completa. Módulo `modules/AdminLanguages` (`module.json`: *"Language management module for localization and translation overrides"*). **No usa ningún paquete tipo `spatie/laravel-translation-loader` o `laravel-translations`**; está escrito a mano. La única dependencia externa es `stichoza/google-translate-php: ^5.3` (`composer.json:21`).

**Tablas** (`database/migrations/2026_04_18_110000_create_database.php:687-713`):
```php
Schema::create('languages', ...);   // name, native_name, code(unique), icon, direction,
                                     // is_default, is_active, auto_translate, sort_order
Schema::create('language_translations', ...); // language_code, key, value(longText), is_custom
                                              // unique(language_code,key) + index(language_code)
```

**Loader decorado** — `modules/AdminLanguages/Providers/AdminLanguagesServiceProvider.php`:
```php
$this-&gt;app-&gt;extend('translation.loader', fn ($loader, $app) =&gt;
    new DatabaseTranslationLoader($loader, $app-&gt;make(TranslationCatalog::class)));
```
`modules/AdminLanguages/Support/DatabaseTranslationLoader.php` solo intercepta el caso JSON (`$group === '*' &amp;&amp; $namespace === '*'`) y hace `array_replace($lines, $catalog-&gt;overridesForLocale($locale))`. Es decir: **archivo JSON = base, BD = override**, y los namespaces de paquetes pasan intactos al loader nativo.

**Caché**: `TranslationCatalog::overridesForLocale()` usa `Cache::rememberForever("translations.overrides.{$locale}")`, invalidado con `flushLocale()` en cada guardado.

**Servicios de soporte** (`modules/AdminLanguages/Support/`):
| Archivo | Función |
|---|---|
| `TranslationCatalog.php` | merge fallback+locale+overrides, paginación para el editor, `saveOverrides`, `import`, `export`, normalización de placeholders |
| `TranslationScanner.php` | escanea `app_path()`, `routes/`, `resources/views`, `resources/themes`, `modules/` con regex `/__\(\s*(['"])(.+?)\1/s` y sincroniza `lang/en.json` |
| `LanguageMaintenanceService.php` | `createLanguage()` (genera el JSON del nuevo idioma) y `updateMissing()` (rellena claves faltantes) |
| `GoogleTranslationService.php` | traducción por lotes de 4000 chars con marcadores `[[I_n]]`, protege/restaura placeholders `:var` y `%s` |
| `LocaleManager.php` | resolución/persistencia de locale |
| `WorldLanguageCatalog.php` | catálogo estático de ~130 idiomas |
| `helpers.php` | `locale_manager()`, `available_languages()`, `current_language()`, `current_locale_direction()`, `language_flag_class()` |

**UI Livewire**:
- `modules/AdminLanguages/Livewire/IndexTable.php` (542 líneas) + `Resources/views/livewire/index-table.blade.php` (365 líneas) → CRUD de idiomas, búsqueda, filtros, bulk select, marcar default (sincroniza `OptionStore` con `config('localization.option_key')`), toggle activo/auto_translate, import de catálogo JSON.
- `modules/AdminLanguages/Livewire/TranslationsPage.php` (147 líneas) + `translations-page.blade.php` → editor clave-por-clave paginado (50/pág) con búsqueda, `saveTranslations()`, `importTranslations()` (upload `.json`), `updateLanguages()` (traducir solo faltantes), `autoTranslate()`.
- Export: ruta `admin-languages.export` devuelve el JSON merged como descarga.

**Salvaguarda inteligente en `saveOverrides()`**: si el valor editado es vacío o idéntico al base, **borra** la fila override en vez de duplicar; y `normalizePlaceholders()` reescribe los placeholders del valor traducido para que coincidan con los del original (protege contra que Google Translate rompa `:count`).

**Rutas admin**: `modules/AdminLanguages/Routes/web.php`, prefijo `admin/languages`, middleware `['web','auth','verified']`. Sidebar registrado en el provider con `register_sidebar_section('localization', 'Localization', 50)`.
